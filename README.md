# Gift Offer Bot

Независимый Telegram-бот для предложений о покупке коллекционных подарков.
Поддерживает inline-оферы и бизнес-команды. Не является официальным сервисом Telegram.
Передача подарка и оплата выполняются вручную. Бот не проверяет их автоматически.

## Запуск

Требуется Python 3.10 или новее.

```sh
python -m pip install -r requirements.txt
python main.py
```

Перед запуском задайте `GIFT_OFFER_BOT_TOKEN` в переменных окружения хостинга
или скопируйте `.env.example` в `.env` и заполните токен.
Никогда не публикуйте токен.

В BotFather включите inline-режим и inline feedback 100%.
Для бизнес-команд требуется бизнес-режим и подключение бота к аккаунту с правом ответа.

## Использование

- `/start` — приветствие.
- `/work` и кнопка «Оставить заявку inline» — автоматическая активация создания оферов.
- Inline: `@имя_бота @продавец https://t.me/nft/PlushPepe-2687 20`.
- `/offer @продавец https://t.me/nft/PlushPepe-2687 20` — создание в личке.
- `/o https://t.me/nft/PlushPepe-2687 20` — короткая бизнес-команда в чате продавца.
- `/business` — состояние бизнес-подключения и последняя ошибка.

В данной конфигурации новые inline-оферы и оферы из лички указывают
`@lovi_lvl` как получателя подарка (константа `INLINE_RECIPIENT`).
Автор офера хранится отдельно. В бизнес-оферах получателем остаётся владелец бизнес-аккаунта.

## Данные и перенос

База `offers.sqlite3` создаётся рядом с `main.py`; храните её на постоянном диске.
База содержит оферы и доступы пользователей и не включена в репозиторий.
При переносе остановите старый процесс, скопируйте базу и запустите одну новую копию.
Не запускайте несколько polling-процессов с одним токеном.
Смена хостинга не гарантирует снятия `PEER_FLOOD`.
